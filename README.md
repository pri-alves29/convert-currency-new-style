# 💱 Instantly Convert Currency

Uma aplicação web simples, moderna e responsiva desenvolvida para realizar conversões de moedas de forma prática e rápida.

---

## 📌 Sobre o Projeto

O **Instantly Convert Currency** permite converter valores de reais entre diferentes moedas. O projeto conta com uma interface limpa, campos de seleção para a moeda de origem e de destino, campo para inserção do valor e exibição dinâmica dos valores convertidos com suporte visual às bandeiras e símbolos correspondentes.

---

## 🚀 Tecnologias Utilizadas

- **HTML5**: Estruturação semântica do projeto.
- **CSS**: Estilização moderna, layout centralizado e design responsivo.
- **JavaScript (ES6+)**: Lógica de conversão, manipulação do DOM.

---

## ✨ Funcionalidades

- Seleção de moeda de origem (*Convert From*).
- Seleção de moeda de destino (*Convert To*).
- Campo dinâmico para entrada de valores.
- Visualização dos resultados com identificadores visuais (bandeiras/símbolos das moedas).
- Interface intuitiva e minimalista.
